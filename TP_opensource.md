### 1. **la difference entre Git et GitHub** :
- a. Git :
Git est un logiciel de gestion de versions distribue, gratuit et open source, qui permet de suivre, enregistrer et gerer les modification apportees aux fichiers d'un projet.

- b. GitHub :
Est une plateforme en ligne qui permet stocker, paratger et de collaborer sur des projets informatiques en utilisant Git. il facilite le travail en equipe et permet de suivre les modifications apportees aus projets.

- ***donc la difference entre le Git et GitHub*** :
Git est un outil de gestion de versions, tandis que GitHub est une plateforme qui utilise Git pour heberger et partager les projets.
